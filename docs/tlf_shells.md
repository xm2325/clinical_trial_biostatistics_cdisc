# TLF shells

All treatment columns use actual treatment (`TRT01A`). Safety tables use the safety population unless stated otherwise.

## Table 1. Demographics

N; age mean (SD); age median [Q1, Q3]; sex n (%); race n (%).

## Table 2. Subject disposition — Randomised population

Randomised N; safety-population n (%); completed n (%); discontinued n (%); discontinuation reasons n (%).

## Table 3. Exposure

Exposure duration mean (SD) and median [Q1, Q3]; observed EX-record count median [Q1, Q3]; maximum recorded dose median [Q1, Q3].

## Table 4. Treatment-emergent adverse-event overview

Safety N; subjects with >=1 TEAE; >=1 serious TEAE; >=1 related TEAE; >=1 moderate/severe TEAE; discontinuation due to AE; total TEAE event count.

## Table 5. TEAEs by system organ class / preferred term

Top preferred terms ranked by overall subject incidence; arm cells display unique-subject n (%). System organ class is carried from `AEBODSYS`.

## Table 6. TEAEs by severity

Subjects with mild, moderate and severe TEAEs by treatment arm. A subject can contribute to more than one severity row.

## Table 7. Exploratory any-TEAE risk difference versus placebo

For each active arm: arm N, placebo N, arm risk, placebo risk, risk difference, 95% Wald CI and Fisher exact p-value.
